# NEXORA — Independent CPM Community

NEXORA is an independent community concept for Car Parking Multiplayer players to present clans, discover teams, and organize community activity.

## Current starter
- Responsive landing page with animated brand intro.
- Create-clan and join-clan dialogs.
- Forms export a local JSON request file only; they do not create accounts, save server records, or provide live chat.

## Brand and affiliation
NEXORA is not affiliated with, sponsored by, or endorsed by the creators or rights holders of Car Parking Multiplayer. The game name is used only to describe the community's focus. Visual identity is original.

## Roadmap
1. Authentication, verified clan ownership, and persistent profiles.
2. Clan discovery, applications, and invitations.
3. Live chat, announcements, and events.
4. Reporting, moderation roles, rate limits, and privacy controls.

## Run
Open `index.html` in a modern browser. No build step is required.
